# MODAS TINA

Sitio web estático de una tienda de moda femenina creado para la pre-entrega de Front-End JS.

## Contenido

- Estructura HTML semántica y navegación interna.
- Catálogo de productos con filtros, generado con JavaScript.
- Sección de reseñas con CSS Grid.
- Diseño adaptable con Flexbox, Grid y media queries.
- Formulario de contacto preparado para Formspree.
- Mapa integrado mediante iframe.

## Ejecutar el proyecto

Abrí `index.html` en un navegador o visitá la versión publicada en GitHub Pages.

## Configurar el formulario

Creá un formulario en [Formspree](https://formspree.io/) y reemplazá `TU_FORM_ID` en la propiedad `action` del formulario de `index.html` por el ID que entregue Formspree. El sitio ya valida nombre, correo y mensaje, y muestra el resultado del envío.
